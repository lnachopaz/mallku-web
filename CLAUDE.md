# Mallku

Sitio web de Mallku. Repo: `lnachopaz/mallku-web`.

## Estructura

Todo vive en `Pagina Web Mallku/`:

- `index.html` — el sitio
- `admin.html` — panel de administración
- `datos.js` — datos del sitio
- `CONFIGURAR-SUPABASE.md` — cómo conectar el backend

## Levantarlo

```bash
cd "Pagina Web Mallku"
npm install
```

Es un sitio estático con Supabase detrás. Leé `CONFIGURAR-SUPABASE.md` antes de tocar datos.
